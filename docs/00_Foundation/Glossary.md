# AutoQA AI — Foundation Glossary

**Version:** 0.2 Draft | **Status:** Canonical vocabulary pending approval

| Term | Meaning |
|---|---|
| Capability | Technology-independent ability the product may provide. |
| Input Provider | Adapter that validates and transforms one external source type into normalized artifacts. |
| Input Source | Versioned source instance supplied to a Project. |
| Normalization | Conversion of provider-specific data into the canonical Domain Model. |
| Engine | Bounded pipeline capability with typed inputs, outputs, evidence and metrics. |
| Agent | Evaluated AI role allowed to use a constrained set of tools. |
| Application Snapshot | Immutable normalized context used by a Run. |
| Observation | Evidence-backed fact discovered from an Input Source. |
| Business Flow | Business interaction/state sequence leading to an outcome. |
| Requirement | Versioned approved statement of intended behavior. |
| Risk | Potential failure with impact, likelihood, detectability and residual exposure. |
| Test Strategy | Approved risk-based selection of verification layers and scope. |
| Test Case | Technology-neutral executable intent. |
| Framework | Automation implementation that realizes Test Cases. |
| Quality Run | Durable orchestration across Engines for pinned inputs. |
| Execution | Controlled attempt to run tests in a defined environment. |
| Evidence | Integrity-checked artifact supporting a conclusion. |
| Finding | Evidence-backed issue requiring classification or action. |
| Bug | Finding accepted as a product defect. |
| Verification | Evidence-based assessment against explicit gates. |
| Approval | Human authorization for a specific action, version and scope. |
| Guardrail | Technical or policy control limiting AI behavior. |
| Provenance | Traceable origin and versions of inputs, transformations and outputs. |
| Knowledge Item | Provenance-linked reusable project or historical knowledge with freshness and access scope. |
| RAG | Retrieval-augmented generation using authorized evidence to construct model context. |
| Model Routing | Policy-based selection of a model/provider for a bounded task. |
| AI Evaluation | Reproducible measurement of AI quality, safety, cost and regression. |
| Integration Connection | Authorized, scoped link to an external service. |
| Metric Definition | Versioned formula and semantics for an operational or product measure. |
| Capability Maturity | Research-to-GA readiness level supported by required evidence. |

This file supersedes duplicate definitions elsewhere. Domain changes update this Glossary, Domain Model, events and affected contracts together.
