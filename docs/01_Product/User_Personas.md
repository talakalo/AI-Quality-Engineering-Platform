# AutoQA AI — User Personas

**Version:** 0.1 Draft

## Maya — Senior Automation Engineer

Needs maintainable code, repository alignment, deep execution evidence and control over changes. Rejects generic generated frameworks and unexplained assertions.

## Daniel — QA Lead

Needs risk coverage, policy, approvals, flakiness visibility, team productivity and reliable release evidence across projects.

## Noor — Software Engineer

Needs quick regression coverage for a feature, actionable failure diagnosis and a small reviewable patch without learning every automation convention.

## Alex — Platform/DevOps Engineer

Needs isolated execution, predictable CI load, observable workflows, short-lived credentials, quotas, recovery and integration stability.

## Sam — Workspace Administrator

Needs user/role management, repository and model integrations, security policy, budgets, retention and audit export.

## Persona requirements

Every major feature identifies its primary persona, job, current pain, expected outcome, permissions, critical errors and measurable success. Personas are validated with interviews before roadmap commitment.
