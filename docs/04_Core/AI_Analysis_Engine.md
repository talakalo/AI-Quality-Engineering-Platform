# AutoQA AI — AI Analysis Engine

**Version:** 0.1 Draft

## Purpose

Convert authorized repository and website observations into a structured, evidence-linked understanding of the product surface, architecture, conventions, dependencies and change impact.

## Inputs

Pinned repository index, discovery map, approved product documents, requirement source, existing tests, relevant history and project policy.

## Outputs

System/component map, conventions, feature surfaces, dependencies, existing coverage, testability gaps, ambiguities, affected areas, evidence links and confidence.

## Rules

Separate observation from inference; cite file/path/route evidence; do not invent business behavior; flag stale or conflicting context; do not modify source.

## Metrics

Groundedness, architecture/convention detection accuracy, relevant-context recall, unsupported-claim rate, expert usefulness score, latency and cost.
