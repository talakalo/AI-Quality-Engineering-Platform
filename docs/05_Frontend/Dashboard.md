# AutoQA AI — Dashboard

**Version:** 0.1 Draft | **Status:** Pending approval

## Information architecture

- Organization and project switcher
- Project overview
- Requirements and traceability
- Plans and approval inbox
- Agent activity
- Runs and live execution
- Findings and failure analysis
- Test inventory and flakiness
- Evidence and artifacts
- Usage, cost and quotas
- Integrations, policies and audit

## Project overview

Show current source version, coverage by risk/requirement, latest runs, open blockers, pending approvals, flaky tests, unresolved findings, cost trend, and readiness—not vanity counts.

## Run details

Timeline of deterministic and agent steps, status, input versions, code diff, test results, artifacts, verification gates, classification, confidence, cost, audit events, and available authorized actions.

## Approval UX

Approvers see requested action, exact scope, diff or command, affected environment, risks, evidence, estimated cost, expiry, and consequences. Approve and reject require an auditable reason for high-risk actions.

## States

Explicit loading, empty, partial-data, stale, blocked, cancelled, degraded, permission-denied, retention-expired, and error states. Live views reconnect without losing durable status.

## Accessibility and responsiveness

WCAG 2.2 AA target, keyboard operation, visible focus, semantic structure, non-color status indicators, screen-reader announcements for live progress, and usable tablet/mobile review flows.
